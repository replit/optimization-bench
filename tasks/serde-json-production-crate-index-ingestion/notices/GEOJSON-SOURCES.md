# GeoJSON input sources

The `geojson-typed` unit reads complete, unmodified GeoJSON files. All of them are
fetch-only: they are downloaded from the pinned URLs below and checked against the
byte length and SHA-256 recorded in `payload.json`, `environment/payload-public.json`
and `tests/heldout.lock.json`. No GeoJSON input body is stored in this repository,
in Git LFS or in the task image, and no held-out output derived from these files is
stored; the held-out manifest records only each expected output's length and
SHA-256. Anyone who downloads the files obtains them from the publisher under the
licence stated for each file below.

## Public split

- Natural Earth vector data (https://github.com/nvkelso/natural-earth-vector, commit
  `f1890d9f152c896d250a77557a5751a93d494776`), 157 files. Made with Natural Earth.
  Free vector and raster map data @ naturalearthdata.com. Natural Earth data is in the
  public domain (https://www.naturalearthdata.com/about/terms-of-use/).
- japan-topography (https://github.com/smartnews-smri/japan-topography, commit
  `b403e71eb97f1fdf32f63d16bd485129f703855e`), 50 files, published by SmartNews Media
  Research Institute for free commercial and non-commercial use. The municipality
  files are processed from MLIT National Land Numerical Information:
  「国土数値情報（行政区域データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/）を加工して作成.

`geojson-typed-inputs.md` carries the same public attribution.

## Held-out split: geoBoundaries gbOpen

194 ADM1 files from the geoBoundaries gbOpen release
(https://github.com/wmgeolab/geoBoundaries, `releaseData/gbOpen/`), downloaded from
`https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/<commit>/releaseData/gbOpen/<ISO>/ADM1/geoBoundaries-<ISO>-ADM1.geojson`.
geoBoundaries publishes each boundary under the licence of its original source.
The licence and source below are copied from each file's geoBoundaries metadata
(`geoBoundaries-<ISO>-ADM1-metaData.json` at the same commit, retrieved
2026-11-17), which also gives the licence and source URLs. Where the held-out
manifest summarizes these files as "CC BY 4.0 / ODbL per boundary source", the
per-file licence below is the accurate one.

Citation requested by geoBoundaries: Runfola, D. et al. (2020) "geoBoundaries: A
global database of political administrative boundaries." PLoS ONE 15(4): e0231866.
https://doi.org/10.1371/journal.pone.0231866
