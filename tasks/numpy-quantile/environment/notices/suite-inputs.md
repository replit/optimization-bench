# Public input sources and attributions

This file covers every public input of this task: the quantile warm batch and the seven public
suite units. The eighth suite unit, `strings-text`, runs on held-out data only. Each prepared
input is derived from pinned upstream bytes, recorded with URL, size and SHA-256 in
`workload/corpus.json` (`parents`, warm batch) and in the task's `provenance.json`
(`suite_units`). The "Changes" column lists every transformation. No value was edited,
imputed or corrected. Attribution statements are reproduced in the form the publishers request.

Held-out inputs are not part of this image. Their sources, licences and attributions ship with
the held-out data in the task's `tests/notices/` directory.

Licence identifiers are SPDX identifiers where one exists. `LicenseRef-` identifiers name the
publisher terms linked in the same row. The full text of CC BY 4.0 is in `CC-BY-4.0.txt`.
