# GNU source archives

The stream-decode workload fetches these complete, unmodified GNU release
archives from the GNU project's mirrors at image build. Each archive contains its
own licence text (`COPYING`, and `COPYING.LIB` where applicable); those files are
the governing notices and travel with the archive bytes unchanged. Using or
redistributing an archive is subject to its licence.
