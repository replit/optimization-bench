# Retained headline scoring policy

The versioned policy is
[`datasets/v1.1-gate-policy.json`](../datasets/v1.1-gate-policy.json).
The filename identifies the inherited policy, not the release's task
membership or qualification. Release membership is in `datasets/v1.0.json`.
The `v1.1` identifiers (the `v1.1-rc` gate profile and
`datasets/v1.1-gate-policy.json`) are inherited identifiers of this scoring
policy, which v1.0 uses unchanged.

The receipt-only adapter `tools.v11_gate_policy` does not run gates, change raw
observations or recompute performance measurements. It projects:

- Exact public and held-out output results.
- Required A/A qualification results. (The inherited v1.1 policy file names
  Intel and AMD classes; scoring is Intel-only.)
- Registered library callbacks: stream faults, in-process repetition and aliasing.
- Process-state and lifecycle results.
- CLI faults when protected metadata declares a public-CLI timed surface and
  the protected hooks register CLI requests.

Header consumers and CPU matrices are reported separately. CLI faults for a
library-timed workload are reported separately too; metadata and registration
derive applicability, not a candidate receipt's assertion.

Missing hooks remain labeled `unmeasured`. An observed callback or state
regression cannot be hidden by omitting its registration label. A registered
hook without passing proof blocks the applicable headline result. These
projection rules do not waive the shared judge's mandatory-gate or registration
requirements.

Authenticated original `baseline_nonrepeatable` and `not_applicable` CLI cases
remain report-only. Other eligible CLI failures still block even when the
overall matrix is nonrepeatable. Missing registered CLI proof is unmeasured and
blocking. Raw classification must come from the verifier, not be inferred by
the adapter.

A projected headline pass is not by itself a claimable performance score;
host registration, current session A/A, quality and final identities still
apply.

This policy implies no new qualification, score promotion or gate
relaxation. See [judge.md](judge.md) and
[statistics-policy.md](statistics-policy.md).
